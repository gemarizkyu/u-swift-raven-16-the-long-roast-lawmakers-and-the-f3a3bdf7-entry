One satirical sentence roasting lawmakers who would regulate AI, crypto or the internet but cannot convert a file to PDF. The program writes the sentence to `/output/entry.txt` — 165 characters, a single sentence, byte-identical on every run.

The roast sets up the lawmaker's authority — a senator grilling AI CEOs — and undercuts it with the file he cannot convert: his staff turns the AI bill into a PDF by printing it out and scanning it back in.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out node main.ts
```
